# BookSales Web

Aplikasi Frontend berbasis **React.js** yang dirancang khusus untuk mengelola sistem penjualan buku.

## Deskripsi
Project ini berfungsi sebagai antarmuka pengguna (UI) yang terhubung langsung dengan **booksales-api** (Backend Laravel). Fokus utamanya adalah memberikan pengalaman pengelolaan data buku yang cepat dan responsif.

## Tech Stack
* **Frontend:** React.js
* **Backend API:** Laravel (booksales-api)
* **Data Fetching:** Axios

## Fitur
* Manajemen data buku (CRUD).
* Antarmuka dashboard admin.
* Koneksi data real-time via API.
